# Hallucination-Aware Verification of LLM Root-Cause Analysis Agents Using Layer-Wise Transformer Internal States

**Domain:** Artificial Intelligence

## Abstract

Large language model (LLM) agents are increasingly tasked with root-cause analysis (RCA) over logs, metrics, traces, and incident records. Their diagnoses are operationally consequential: an unsupported root cause can send responders to the wrong service, hide a genuine fault, or justify an unsafe remediation. Hallucination in this setting is not the same problem as hallucination in short-form question answering. An RCA agent can quote a real log line, name a real service, and still assert a causal link the evidence does not support. It can invent a missing span, merge distinct faults into one story, or state a single root cause with confidence the observations do not warrant. Lexical overlap with retrieved context, citation checks, and self-consistency therefore miss a large class of errors. The explanation can be locally faithful to the text and still be causally false.

This project develops a hallucination-aware verifier for LLM RCA agents that reads layer-wise transformer internal states rather than the finished token string alone. The working hypothesis is that unsupported causal claims, fabricated evidence, and overconfident fault attributions leave separable signatures in the residual stream as depth increases. Early layers primarily carry the lexical form of retrieved observations. Intermediate layers concentrate features that truthfulness probing has associated with factual commitment. Later layers mix those features with the pressure to emit a fluent incident narrative. The verifier records hidden states, attention summaries, and intermediate next-token predictions (via the logit lens) both while the agent conditions on tool observations and while it generates the diagnosis. Lightweight probes, trained per layer and aggregated across depth, score four related but distinct failure modes: evidence grounding, causal entailment, entity fidelity, and calibration of the stated cause. Treating “hallucination” as one label would collapse these modes and hide which internal signal is actually informative.

Evaluation uses agent trajectories on controlled microservice and distributed-system failure benchmarks, with labels for supported and unsupported diagnostic claims derived from the known fault injection and from the evidence the agent actually observed. Baselines include token-level uncertainty, semantic entropy, retrieval and citation consistency, and a black-box LLM judge. The study asks which layers carry usable signal, whether that signal transfers across model families and incident domains, and whether acting on a high-risk score—abstention, a request for missing evidence, or a ranked set of alternative causes—reduces unsupported diagnoses while preserving correct ones.

The contribution is a white-box verification layer for agentic RCA: a layer-resolved account of where unverified causal commitments form, a probe-based detector that can run alongside generation, and an evaluation protocol that measures hallucination in multi-step diagnosis rather than in isolated factual answers.

**Keywords:** large language model agents, root-cause analysis, hallucination detection, transformer internal states, layer-wise probing, residual stream, AI reliability
